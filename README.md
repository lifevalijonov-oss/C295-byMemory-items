# C-295 Memory Items

Тренажёр memory items (жирный текст) аварийных процедур C-295MW по A.O.M. (P.) C-295MW-UZ01-1, Section IV — 26 процедур.

Режимы: Очередь (интервальные повторения), Читать, Вспомнить, Написать, Порядок, Сценарий, Тест. Работает без интернета, прогресс хранится на устройстве.

## Как получить APK

Сборка идёт автоматически при изменении `index.html` (или вручную: Actions → Build APK → Run workflow). Готовый `C295-Memory-Items.apk` появляется в **Releases**.

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение |
| `manifest.json`, `icon-*.png` | Иконки, установка как веб-приложения |
| `debug.keystore` | Ключ подписи (чтобы обновления ставились поверх) |
| `.github/workflows/build-apk.yml` | Сборка APK через Capacitor |
